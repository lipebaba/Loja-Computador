# 🖥️ API Loja de Computadores

Uma API REST desenvolvida em Django para gerenciamento de produtos de uma loja de computadores.

## 📋 Funcionalidades

- Listar produtos
- Buscar produto por ID
- Cadastrar produtos
- Atualizar produtos
- Excluir produtos
- Integração com PostgreSQL

## 🚀 Tecnologias Utilizadas

- Python 3
- Django 6
- PostgreSQL
- Git
- GitHub
